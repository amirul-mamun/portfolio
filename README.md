# 🌟 Amirul Mamun – Portfolio

A modern, responsive portfolio website showcasing my skills, projects, and achievements in **web development**. This project is designed to highlight my technical expertise and provide a professional online presence.

---

## 🚀 Features
- **Responsive Layout** – Works seamlessly across desktop, tablet, and mobile.
- **Interactive UI** – Smooth navigation and dynamic elements with JavaScript.
- **Custom Styling** – Clean, modern design using CSS.
- **Project Showcase** – Dedicated section to highlight my best work.
- **Contact Integration** – Easy access to email and social profiles.

---

## 🛠️ Tech Stack
- **HTML** – Structure and content
- **CSS** – Styling and layout
- **JavaScript** – Interactivity and dynamic behavior
